A memory system for the people in your life. It listens for twenty seconds after you leave a room, files what you said against the right person, and hands it back the moment you need it. The phone is live — tabs, filters, search and voice capture all work.

The palette

A pine ground rather than a black one, so the warm accents read as light in a room instead of neon on a void. Gold is the app's own voice: live, matched, act now. Coral is reserved for one meaning only, and nothing else is allowed to be that saturated.

What changed, and why

No cards
Rows sit on the ground, separated by hairlines. A border around everything says every item is equally important, which flattens the screen. Now type size and weight carry hierarchy and the only lifted surfaces are the ones you act on.
No stripes
The colored left rail is gone. A person's circle now reads as a 6px square beside their name and as the fill behind their initials. Same information, a tenth of the ink.
Square corners
Zero radius everywhere except the record button and the mic, where a circle means "press me". Squared initials read like a card index, which is what this actually is.
Underlines, not pills
Filters are text with a sliding rule under the active one. Pill chips are the most recognizable generic-app tell there is.
Warmth as a meter
A 2px hairline that fills on mount, instead of a ring around an avatar. It reads as data, not decoration, and it scales down to a list row.
Three typefaces
Fraunces for names and headings, because a person's name deserves a serif. Schibsted Grotesk for interface text. DM Mono for anything countable: dates, distances, confidence, status.

Motion

Every animation here answers a question the user is already asking. None of them are ambience, and all of them stop under prefers-reduced-motion.

List entry
Rows rise 11px on a 34ms stagger. Tells you the screen changed and gives the eye an order to read in.
Locator ping
Two expanding rings on the place marker. The only honest way to say "this is live right now".
Waveform
Canvas, not CSS bars. It reacts to the recording so you can see it is hearing you, which is the whole anxiety of a voice interface.
Transcript type-on
Words appear as they are recognized. Turns two seconds of waiting into two seconds of watching.
Extraction reveal
Found items stagger in field by field. It shows the work rather than dumping a finished form on you.
Check-off
Tick springs, row fades to 42%. The item stays on screen so you can undo, but stops competing for attention.
Meter fill
Warmth animates from zero. Draws the eye to the number that is the point of the row.

The demo-data seam

Every record on the phone comes from one fenced block, and no view function touches it directly. Views call an async store. Swapping to live data is two edits and one delete, with no way to end up half in each world.

/* ═══ DEMO DATA — DELETE EVERYTHING TO THE END MARKER ═══ */
const DEMO_PEOPLE = [ ... ];
const demoStore   = { ... };
/* ═══ END DEMO DATA ═══ */

const DATA_SOURCE = "demo";   // "demo" | "live"

const liveStore = {
  people:  () => api("/api/v1/people"),
  today:   () => api("/api/v1/today?lat=..&lng=.."),
  search:  q  => api("/api/v1/search?q=" + q),
};

const store = DATA_SOURCE === "demo" ? demoStore : liveStore;
One switch
Set DATA_SOURCE = "live", delete the fenced block, ship. If you forget to delete it, the constant still means nothing reads it.
Both async
The demo store returns promises too, so the live store is a drop-in. No render code changes when you switch.
Tagged records
Every demo record carries _demo: true. If one ever reaches a database, one grep finds it.
No fallback
The live store never falls back to demo on error. It shows an empty state. Silent fallback is exactly how preview data ends up in production.
Visible badge
A gold DEMO flag sits in the status bar whenever the demo store is active. You cannot look at a screenshot and not know.

Names, places and events on the phone are invented. Nothing here reads from your real contacts, and the demo store makes no network calls at all.
